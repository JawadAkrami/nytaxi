## NYC Taxi Data Analytics  

This project dives into the world of New York City taxi data and walks through the full data science workflow from start to finish. Instead of just throwing together a few charts, this project breaks down millions of taxi rides to figure out what is really going on behind the scenes — from ride patterns and passenger behavior to trip predictions and business insights.

The project is split into two main notebooks along with an interactive dashboard:

* [Project 1](https://github.com/JawadAkrami/nytaxi/blob/main/nytaxi_p1.ipynb) focuses on data cleaning, preprocessing, and exploratory data analysis.
* [Project 2](https://github.com/JawadAkrami/nytaxi/blob/main/nytaxi_p2.ipynb) moves into feature engineering and data analysis.
* [Dashboard](https://github.com/JawadAkrami/nytaxi/blob/main/taxi.jpg) brings the results together through interactive visualizations and insights.

The idea behind this project was to take raw transportation data and turn it into something meaningful. Along the way, the notebooks dig into questions like:
When do taxi demands spike up? Which areas rack up the highest fares? How do weather, time, and traffic patterns affect trip durations? What factors stand out the most when predicting ride behavior?

To answer these questions, the project pulls together several data science techniques, including exploratory data analysis, statistical insights, feature engineering, and machine learning modeling. The workflow also cleans up messy real-world data, such as handling missing values, and filters out anomalies.

One of the strongest parts of this project is how it connects technical analysis with storytelling. Instead of overwhelming users with raw numbers, the dashboard helps break things down visually so the trends are easier to follow. Users can click through the insights, explore ride activity across the city, and get a better feel for how NYC transportation flows throughout the day.

This project was built using tools and libraries commonly used in real-world analytics, including Python, Pandas, NumPy, Matplotlib, and Seaborn. The goal was not only to build models but also to show how data can be cleaned up, explored, modeled, and presented in a practical and understandable way.

Working on this project helped bring together multiple parts of the data science process — from digging through raw datasets and figuring out patterns to building models and presenting results clearly. It is a hands-on example of how analytics and machine learning can come together to solve real-world problems using large-scale urban transportation data.
